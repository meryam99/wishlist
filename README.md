# Wish List App 

Test task: application for managing personal wishes.  
Built using **React + TypeScript + TailwindCSS** and **JSON-server** for local API.

## 🚀 Features
- Add, remove and edit wishes
- Sorting by price and date
- Pagination & modals
- Validation & inline notifications

## 🧱 Tech Stack
- **React**
- **TypeScript**
- **TailwindCSS**
- **JSON-server** 
- Custom Context state management

## ▶️ Run locally

```bash
# Install dependencies
npm install

# Run frontend
npm run dev

# Run backend (JSON-server)
npx json-server --watch db.json --port 4000
